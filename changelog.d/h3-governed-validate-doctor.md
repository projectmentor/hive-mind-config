New `hconfig validate [MODULE]` (the core's validators plus the node keys against the core schema) and a full `hconfig doctor` (key-dir mismatch, agent-socket-dir mismatch, env override, governed value out of range, unknown or invalid keys, audit file mode, node file edited outside hconfig, daemon not restarted).
