- hconfig 0.1 (H2): `hconfig set` and `unset` for `node:` keys and node-scope module keys, through `hv config node set` and `hive-mind module config … set|unset`. Type, enum and bounds are checked before a verb starts; a secret is accepted only with `--stdin` and reaches the core on stdin; the no-op check compares the layer written; refusals are typed (`secret-on-argv`, `env-overridden`, `owner-only`, `read-only`, …) with exit 1; writes serialize on one flock and append a 0600 line to `$HIVE_HOME/hconfig/audit.jsonl`. Owner-signed keys (`core:`, fleet, fleet-node) and `node:owner_quota` are refused as `owner-only` with the command to run.
