- hconfig 0.1 (H1): the read side. `hconfig schema|list|get|explain` (text and `--json`) build one registry of node, module and governed keys from the core's own verbs (`hv config schema|show|node list`, `hive-mind module list` and `module config <name> schema|list`), mask secrets, and mark each key's visibility and write path. The manifest is contract 1 (`cli: hconfig`, `reads: []`, no service, `min_core` 4.0). Nothing is written, no key is held. The publisher key is not provisioned, so the tree is unsigned.
